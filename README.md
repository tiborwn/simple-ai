# Simple AI models examples
Written for studying AI and ML

### icecream-sales
>#### Provide the temperature and get sales amount (low / high).
>- **1 input neuron**
>- **1 output neuron**
>- Output activation: Sigmoid
>- Loss: Mean Squared Error
>- Optimizer: Stochastic Gradient Descent (batch size = 1)

### comfortable-temperature
>#### Provide the temperature and find out how comfortable is it (uncomfortable / comfortable).
>- **1 input neuron**
>- **2 hidden neurons**
>- **1 output neuron**
>- Hidden activation: ReLU
>- Output activation: Sigmoid
>- Loss: Mean Squared Error
>- Optimizer: Stochastic Gradient Descent (batch size = 1)

### worth-to-run
>#### Provide the temperature and weather to find out is it worth to go running (uncomfortable / comfortable).
>- **2 input neurons**
>- **3 hidden neurons**
>- **1 output neuron**
>- Hidden activation: ReLU
>- Output activation: Sigmoid
>- Loss: Mean Squared Error
>- Optimizer: Stochastic Gradient Descent (batch size = 1)
